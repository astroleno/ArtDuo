# 前端连续性修整与双域名发布 · 2026-10-28

按用户对[综合评审](../reviews/artduo-frontend-review-summary-2026-10-28.md)的决定完成本轮修整，并发布到 [aitoshuu.me](https://aitoshuu.me/ArtDuo) 与 [tongye.me](https://tongye.me/ArtDuo)。首页的居中问句、五秒翻牌、柔和明暗、透明底线输入与液态玻璃按钮保持原样；展厅的随动幅度、静观与边缘唤回保持原样。

人物雕塑继续作为独立彩蛋，不按绘画中的人物题材排除。18 件池、50% 单次机会与原路线续接保持不变；明确不看雕塑或限定媒介的条件继续有效。
