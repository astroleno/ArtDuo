# 观展性能与真实感复核

线上复看 11 月 19 日 739 版「刚拿到 offer」的已保存展览。桌面能看出墙面、画框和作品的层次，窄屏仍能看全第一件的纸边并读到展签。两个可复现的问题影响连续性。前言和第一间展厅会各下载一次同一面墙，右侧来光时画框也缺少对应的右边亮缘和向左投影。墙面、装裱和光向是本轮优先保留并校正的空间线索。

Astra 制定改动顺序和验收标准，Sol 实现，Astra 独立复核。第一批给当前作品、墙面与相邻预览更高的加载优先级。第二批用场景已有的光向校正画框。墙面与装裱在静态画面中也提供空间感，动态光照按需重绘。

## 第一批 · 首墙和换画

前言、预载和展厅统一使用同一组响应式墙图与跨域加载方式。当前作品和墙面就绪后，依次预热下一件预览及不同的墙面，再预热上一件，最后安排可选的深度图。系统减少动态效果或关闭「画面轻动」时跳过相邻深度图。3G 只预热下一件预览，省流量与更慢的网络跳过预热。共享队列将并发维持在两项，并合并同一资源的排队请求。

以同一场已保存展览在本机生产构建中复测，固定六件作品、预览图和入展路径。每个视口与缓存组合有三次有效样本。点击计时到作品就绪事件，并确认对应作品和墙面解码、过渡结束。一次桌面默认缓存导航等待浏览器 `load` 超时，已补跑。

## 第二批 · 画框受光

左侧和右侧来光时，入光侧的画框边缘变亮，近、远投影分别向另一侧偏 5px、11px。顶光的静止投影垂直向下。贴墙的短阴影提供接触感，纸本装裱带出画与墙的距离。

Astra 独立对照桌面纸本、手机视口布面作品和左、右、顶三种光向。六组前后对照的作品、墙图地址与画框、展签几何一致，两种视口均无横向溢出。另在桌面普通动态和手机视口减少动态下，从前言依序看完 offer 场六件作品并打开结语。桌面「画面轻动」可关闭与恢复，手机视口随系统减少动态关闭了该选项。579 项测试、工作区类型检查和 Web 生产构建均通过。
