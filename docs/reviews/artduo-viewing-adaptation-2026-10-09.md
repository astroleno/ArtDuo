# 观看反馈与展厅迭代验收

本轮按[已确认方案](../plans/artduo-viewing-adaptation-2026-10-09.md)实施，沿用现有分支。数据来源仍为 `2026-10-06-paintings` 的作品元数据、题材 / 色彩 / 构图标签，以及现有展厅图片；未新增馆藏或远程行为采集。

## 已实现的体验

- 展厅限定为经过视觉核对的 `bg-004`、`bg-027`、`bg-034` 正面展墙；按绘画与纸本设置画框、衬纸和接触阴影。移除画作转场中的模糊与亮度滤镜。窄屏沿用安全布局与中性展墙降级。
- 小展签打开独立阅读层：桌面侧边阅读，手机全屏阅读，正文独立滚动。原有画作位置不变，支持 Escape、焦点约束和关闭后的焦点恢复。
- 初始顺序保持首件及阶段归属，利用真实题材、色彩和构图标签改善阶段内相邻关系；连接说明只引用共同题材、相同作者或明确的比较建议。疲惫 / 休息意图使用“入场 / 停留 / 余韵”和较低转场强度。
- “本次展览”提供更安静、多看这类、换一种题材、保持原路线四种明确选择。选择先成为待应用决定，在下一次进入未看部分时重排尾部；当前作品与已走过的前缀固定。回看期间提出的选择会等待走回未看边界。可取消待应用决定，或恢复剩余部分的原始顺序。
- 稳定作品单元 ID 不再依赖排名。重排不增加或移除作品，不能突破原始选集与排除条件；已走过的位置保留原来的房间，后续作品承接目标位置的阶段与房间。
- 刷新、作品详情返回、新标签页分享链接及浏览器前后退保留路线和位置。URL 仅接受原始合格作品集合的完整排列。

## 观看记录与节奏

观看、放大和阅读分别计时；只在作品已解码、页面可见且转场结束后计入有效观看，后台、加载失败及转场暂停。至少三件已结束观看的作品才参与节奏判断；节奏仅影响换画时长和环境微动，不自动改变内容方向。用户可关闭节奏跟随、清除记录。

记录只写当前标签页的 `sessionStorage`，包含版本、作品身份、计数与长度校验；存储不可用时继续内存浏览。URL 不包含观看记录。此功能不读取眼动、传感器或其他用户数据，不推断情绪。环境音仍由用户开启；阅读时降至设定音量的 40%，关闭阅读后恢复，播放速度保持 1 倍。

## 验证记录

- 全仓单元测试 **243/243**：contracts 38、UI 30、corpus 40、API 41、web 53、pipeline 41。新增覆盖前缀冻结、恢复剩余路线、完整候选集合、无变化处理、稳定身份、静态资源保持、阶段约束、计时、存储与 URL 校验。
- 浏览器完整回归首轮 **41/41** 通过。补充前后退测试后，发现“退回初始位置”被旧的位置去重逻辑忽略，以及恢复期间可能写回旧 URL 的问题；修复为识别每次外部位置恢复，并等待恢复完成后再发布位置。四项观看反馈用例复跑通过。
- 修复后的完整浏览器回归 **42/42 通过（3.3 分钟）**，覆盖 classic 与 experience 两种入口；全仓类型检查和生产构建通过，测试专用路由未进入生产构建。
- 阅读音量降至 0.064、关闭后恢复 0.16、播放速度始终为 1 的断言通过。连续切换 20 次及卸载 / 重挂 3 次的资源测试通过；WebGL 程序峰值为 1，卸载后资源释放。
- 桌面、320 / 390 px、844 px 横屏布局、阅读滚动、键盘与焦点恢复通过。视觉证据：[桌面展厅](../assets/experience-integration-acceptance/walk-1440.png)、[320 px 展厅](../assets/experience-integration-acceptance/walk-320.png)、[手机阅读层](../assets/experience-integration-acceptance/reading-390.png)、[观看反馈](../assets/experience-integration-acceptance/feedback-390.png)。
- 本机生产服务五轮对照通过：相同查询与 1440×900 视口，服务端预热、每轮新建浏览器上下文。首画可操作中位数为 classic **738 ms**、experience **556 ms**，差值 **−182 ms**；experience 最慢 **564 ms**，满足额外延迟不超过 500 ms 的门槛。此结果只代表本机桌面条件，见[原始测量](../assets/experience-integration-acceptance/performance-2026-10-09.json)。

## 保留的人工门槛

继续以 classic 为默认入口。此前音轨授权与实听、真实触摸设备、实际读屏、原生 200% 缩放及正式深度图样本的验收仍开放，本轮自动化没有替代这些验证。未合并或部署。题材匹配和节奏判断使用可解释的有限规则，不代表通用语义理解或情绪识别。
