## 1. 已确认的产品方向

| 方面 | 综合结论 | 后续约束 |
| --- | --- | --- |
| 首页 | 居中问句、柔和背景、透明输入与细底线、一个主动作，已经符合最初希望恢复的旧版感觉 | 保留明暗切换、每五秒翻牌；输入、提交、页面隐藏及减少动态时暂停。错误留在输入下方，不补回框、斜光、解释卡片或第二套入口 |
| 视觉语言 | LuBirth 对齐的液态玻璃用于操作，纸质展签用于作品与阅读，两种材质有清楚分工 | 一致性主要体现在动作、触区、反馈与返回规则；没有必要把每个面都做成玻璃或使用同一种背景 |
| 观看节奏 | 作品居中、静观淡出、边缘唤回、用户自行换画，是当前沉浸体验的基础 | 默认克制跟随；手机感应明确开启。保留关闭随动和减少动态，不把静观改成自动换画或持续动画 |
| 雕塑空间 | 使用清理后的独立雕塑，放进 ArtDuo 的展厅。去掉的是扫描附带街景和杂物，展厅仍承担空间参照 | 模型朝向固定、视点轻微变化；雕塑背景不做位移视差，允许弱于雕塑的补光；保留雕塑内部、底座交接与落地处的 AO / 接触阴影 |
| 雕塑内容 | 正式池保持十八件，《加莱义民》完整群像正式入池；后来替换的六件是《加莱义民》《思想者》《掷铁饼者》、苏格拉底、巴尔扎克、贝多芬 | 以可识别名作和人的经验支撑内容，不再用任意匿名日常扫描凑数。“人民史观”体现在共同处境、思考、身体实践与创作的介绍里，不虚构作品的阶层或历史身份 |
| 雕塑偶遇 | 每个符合条件的观展会话一次 50% 机会，最多一件；刷新、返回与继续不重抽 | 不等于每次必有，也不等于每次换画抽一次。侧厅可略过，继续后接回原绘画路线，不增加绘画计数 |
| 意图边界 | 人物雕塑按独立艺术品理解。“无人海景”“不要人物”不能自动变成禁止人物雕塑 | 明确“不看雕塑”或“只看某种绘画媒介”应约束彩蛋；不把普通题材偏好无限扩大成媒介排除 |
| 文案与资料 | 事实介绍、观展短文、详细讲解各有用途 | 事实与来源独立保留；AI 不编造材质、年代、作者或扫描缺失部位；正在阅读的文字保持稳定；详细讲解、分享与手写仍由观众主动选择 |
| 结语 | 用最后一件作品与短句收束，允许回看、保存与手写 | 不自动把末件近看送到结语，不让分享或制作纪念品成为完成观展的前提 |

## 2. 多轮意见应如何合并

判断依据依次是：**用户最新的明确决定、对应版本的源码与操作证据、稳定截图、评审者的设计建议。** 多个模型认同同一建议能帮助定位重点，但不能替代真实用户观察或实机验证。

- 第一轮 [Lama](artduo-frontend-lama-review-2026-10-28.md) / [Emil](artduo-frontend-emil-review-2026-10-28.md) 主要发现等待反馈、动作名称、辅助路线、设置语义和近看控件的问题。这批主要修整已经上线。
- 第二轮 [Lama](artduo-frontend-followup-2026-10-28/lama-review.md) / [Emil](artduo-frontend-followup-2026-10-28/emil-review.md) 检查修整后的版本，问题转为返回语义、失败恢复和明确媒介限定。
- [Kimi K3.1 Pro](artduo-frontend-two-model-2026-10-28/kimi-k3.1-pro-review.md) 与 [DeepSeek Flash](artduo-frontend-two-model-2026-10-28/deepseek-flash-review.md) 分别审阅相同的 49 份源码、15 张截图和中性观察，未读取前两者的结论。它们补充了自然否定语、原地重试等细节，也提出了不应直接采纳的泛化建议。
- 两轮 Lama / Emil 都由主线程统一采集各自轮次的浏览器证据；Kimi / DeepSeek 复用第二轮材料。因此这是多个独立判断，不是四组独立实机研究。共享材料中关于雕塑 AI 的范围错误已经[勘误](artduo-frontend-model-comparison-2026-10-28.md)。

主线程本次重新查看了当前版本的首页、静观展厅、《加莱义民》手机预览和阅读失败态原图。我的判断是：首页的留白、展厅的作品主次、独立雕塑的空间关系都足以支撑既定方向；失败阅读区的大块空白则直接浪费了可读面积。静态图不能证明动效流畅或手机性能。

| 顺序 | 具体问题与证据 | 建议处理及涉及模块 | 验收重点 |
| --- | --- | --- | --- |
| 1 | **近看换画预备图失败后一直准备。** I12 定向拒绝下一张离 DOM 图片的解码；5.2 秒后 URL 已到下一件，可见图与署名仍为上一件，前后按钮禁用。关闭仍可用。这是受控分支，不是自然事故频率统计 | `ImageLightbox` / `ImmersiveDetailStage` 区分准备、成功、失败；失败保留匹配的旧图和署名，原区域提供重试或取消切换；与展览位置协调，避免退出后落到另一件 | 失败不再无限等待；取消留原作，重试成功后图、署名与位置一致；关闭始终可用；单独高清失败仍能保留已就绪预览 |

这四项对应同一条体验要求：观众暂时离开全景去近看或阅读之后，能够理解当前状态，并轻松回到同一件作品。修复应该降低操作和注意力成本，不增加新的解释页面。

## 4. 不直接采纳的建议与尚需观察的选择

| 建议 / 分歧 | 综合判断 |
| --- | --- |
| 雕塑短文必须增加“生成”按钮 | **不采纳为必修。** Kimi 识别到自动请求属实，但共享 brief 将“详细讲解按需”泛化成了所有 AI 文案。既有方案已批准缓存的主题观展短文；它不阻挡模型显示，失败有固定提示，打开的阅读正文也被冻结。继续区分短文与详细讲解 |
| 阅读必须立刻开文字层、随后补图 | **不直接改。** 图片就绪后打开、期间有反馈和取消，是此前确认的策略。先处理失败布局与恢复。只有新的等待证据表明现有策略仍造成明显阻碍，再比较文字先开的方案 |
| 静观时把右上设置入口也完全隐藏 | **保留当前折中。** 它提供一个稳定的可发现入口。DeepSeek 的全隐藏建议与 Lama 对导航再发现的担心相互牵制，不能以“更干净”直接裁决 |
| 首次观看增加提示，或中央移动也唤醒 | **先做首次用户观察。** 当前中央看画、边缘唤回按已确认策略工作；没有首次用户受阻的有效证据。若确有问题，再比较轻量首次提示，不先加常驻层 |
| 末件近看直接结束，或增加完成入口 | **保留主动收束。** 当前可关闭近看，再“看完了”，并回看原末件。自动结束不符合既定节奏；额外入口是否值得增加尚无充分依据 |
| 继续加强雕塑光效、旋转或扩大模型池 | **本轮无此依据。** 已确认目标是克制视差、稳定背景、较弱背景光与接触关系。十八件已经完成选池目标；后续逐件构图问题应逐件处理，不重新扩张产品 |

关于雕塑 AI，上一轮“没有手动生成”曾被误写为“没有触发请求”。已更正：预览挂载会自动调用接口；当时是否命中缓存或实际生成未监测。它不构成要求重做文案交互的证据。

## 6. 不能被这轮 UI 共识关闭的验收缺口

**首画等待是现有记录中更重要的整体体验风险。** 历史一次新策展首画为 32.059 秒，未达到 8 秒目标，用户已同意性能验收后续进行；最近上线记录明确保留这一例外。本轮使用旧展览回放，没有重新测新策展，因此既不能说现在仍普遍耗时 32 秒，也不能说已经达标。下一阶段应单独测量从输入到首件可看的实际过程，再决定优化环节；延长入场动画或增加进度说明无法替代它。

其余需要补验的范围如下，不作为已发生故障，也不记为已通过：

- 真机 Safari / Android、软键盘与安全区、手机感应授权 / 拒绝、展厅—近看—雕塑之间的感应状态连续性、低端 GPU 和帧率。
- 首次观众静观后能否找到继续、近看与返回，尤其是触屏；没有数据支持继续隐藏入口或增加提示。
- 指针在近看入场中途退出的连续性；现有复评关闭样本实际已经进入 `open`，不能证明或否定入场跳变。此前 Escape 与焦点恢复的通过记录保留。
- 第二轮 F15 只证明结语结构和回看路径，当时末件图片未完成解码；不能当作该版本结语图像终态验证。第一轮稳定图也不能替代新版本终态。
- 雕塑已有 10/27 的自然偶遇、返回原路线、状态持久化与资源验证；这不等于验证了长期 50% 样本分布，后续复评的单件预览也不能代替完整随机流程或实机全池表现。

下一轮前端实施建议限定为第 3 节四项，并在同一轮回归现有正常路径；性能和真机验证另按已有未完成事项继续跟踪。验收时检查错误能否恢复、作品与位置是否一致、操作是否立即回应、阅读是否稳定，首页信息量与观看节奏也应一起回归。当前证据不支持再开启一轮全面视觉重设计。
