# ArtDuo experience 接入验收记录

本文记录接入基线、自动化结果和人工验收证据。只在对应证据实际产生后更新结果；未完成的人工设备、读屏、性能或来源核验不会标为通过。

## 2026-10-03 引导、视觉与画作范围修订

依据用户本轮要求，缩短引导文案，使用 taste skill 对照 `experience/` 与 Silent Meridian 的留白、低密度控制和作品优先原则调整界面；同时解决主展览混入非画作的问题。

- 入口文案收敛为“想看些什么？”；输入直接进入首件，示例可一键提交。引导仅保留“12 件作品，点击画作可放大。”一类与实际数量一致的短句，随“本次展览”按需展开。旧 `phase=preface` 直达仍有效，取消逐字等待和重复按钮。
- 移除观展时常驻的情绪轨道和重复英文标识，阶段导航保留在可选展览说明内；展签缩到 230px，完整标题及元数据仍可展开；结语保留最后一幅画，收起装饰性曲线和 release 技术标识。
- 手机画框清除旧版共享样式强制的 4:3 / 3:4 比例，图片按真实解码比例完整放入画框；回归检查图片边界与画框边界，而不只检查页面无横向滚动。
- `searchReleaseCatalog` 在向量候选截断前过滤作品类型，classic、experience 和路线预览共用该结果。保留油画、水彩、素描、版画等平面画作；器物、雕塑、建筑构件、摄影、整本古籍和缺少类型证据的记录不再用于凑足 12 件。作品题名中的建筑、花瓶、雕塑只是题材，不触发类型排除；油彩木板画也不会因 wood 被误判为器物。
- 当前 `2026-04-25-curation-b` 共 221 条记录：129 条进入画作候选，86 条排除为非画作，6 条类型不明暂不参与。原始 release 文件、ID 和详情可访问性不变。[逐项分类与六类查询结果](../assets/experience-integration-acceptance/painting-eligibility.json)保留核验依据；此结果验证作品类型，不等于情绪相关性已经通过。
- 对两条“Paintings”分类例外核对了官方藏品说明：[仪式冠 `met-37789`](https://www.metmuseum.org/art/collection/search/37789) 实为佩戴的五片式礼仪冠，[经文残卷 `met-902212`](https://www.metmuseum.org/art/collection/search/902212) 以经文书写为主。两条均不进入本轮绘画候选；例外保留稳定 ID、理由及来源链接。

画作数据补充任务已整理为[可转发的提示词](../prompts/artduo-classics-corpus-handoff.md)，要求真实图像样本、官方类型证据、出处与权利记录、字段映射和候选验证，不覆盖正式 release。

### 本轮验证结果

- 单元测试 221/221 通过（contracts 38、corpus 40、UI 22、pipeline 40、web 40、API 41）。新增检查覆盖画作与器物的区分、先过滤再截断候选、没有合格画作时返回空结果，以及默认直接进入首件。
- 全仓类型检查和构建通过；最后一次结语图片状态调整后，UI / web 类型检查及 web 生产构建再次通过。生产路由表不含临时测试入口。
- 完整 37 项 E2E 批次为 35 通过、2 失败：桌面入口等待路由超过 20 秒，详情跳转等待标题超过 5 秒。保留这些开发服务加载超时记录，未将该批次或最初中断的预检记为全通过。随后在相同源码的生产构建中单独复测这两项，2/2 通过，分别用时 41.4 / 9.8 秒；合并覆盖全部 37 项，不代表单次完整 E2E 全绿。
- 已检查桌面入口、展厅、结语和分享图，以及 320 px 简版展厅截图。结语等待作品实际加载后取图；移动端检查真实图片没有超出画框，完整标题与展签仍可展开和滚动。

### 当前入口的五轮生产性能

2026-10-03（Asia/Shanghai），同一台 macOS、Chromium、1440×900、本地生产服务，服务端预热、每次新建浏览器上下文。query / release 与上文一致；起点为提交，终点要求图片解码、有限动画结束和下一件按钮可命中。[本轮原始数据](../assets/experience-integration-acceptance/performance-2026-10-03.json)与历史数据分别保存。

| 路径 | 首件可见中位数 / 最慢 | 首件可操作中位数 / 最慢 |
| --- | --- | --- |
| classic | 2548 / 2696 ms | 2548 / 2696 ms |
| experience，直接进入画作 | 2507 / 4439 ms | 2507 / 4439 ms |

同批次可操作中位数差为 **−41 ms**，满足“不额外增加超过 500 ms”的预算；最慢一次仍为 4439 ms，不能据此声称整体明显提速，也不代表手机或弱网表现。复现时先构建并启动 `127.0.0.1:3220` 的生产服务，再从仓库根目录运行：

```sh
ARTDUO_PERFORMANCE_OUTPUT=../../docs/assets/experience-integration-acceptance/performance-2026-10-03.json pnpm --filter @artduo/web exec node scripts/measure-experience-performance.mjs
```

下方 2026-10-02 的数量、选集和强制前言性能属于修改前的基线。作品类型问题已按本轮规则处理，情绪相关性仍未通过：例如疲惫查询首作仍为蒸汽船火灾版画。音频授权 / 实听、正式深度图、真实触摸设备、读屏与原生 200% 缩放的既有验收缺口未因此关闭，默认入口仍为 classic。

## 2026-10-02 修复与复验

工作树基于 `10f8ad2`，本批次未提交、推送或发布。环境为 macOS、Next.js 15.5.3、项目现有 Chromium / Playwright，正式馆藏版本仍为 `2026-04-25-curation-b`。

**该批次自动化结果：** 冻结依赖安装通过；完整 `pnpm preflight:check` 通过，包含 217/217 单元测试（contracts 38、corpus 40、UI 22、pipeline 40、web 36、API 41）、类型检查、构建和 36/36 E2E。完整四幕流程同时检查页面标题、URL、真实图片解码、操作和控制台错误；测试中的失败注入有独立恢复断言。

| 已确认问题 | 修复与证据 |
| --- | --- |
| 所有 mount zone 被误判为无效 | 区分源数据的 0–1 坐标与投影后的像素边界；回归用例验证两个有效挂画区域产生相差 800 px 的实际画框，且不进入 fallback。缺失、裁出视口和非法区域仍安全降级。 |
| 作品图片尺寸覆盖背景尺寸 | 背景投影只使用背景尺寸；作品比例来自实际解码后的图片，避免背景和作品的加载顺序改变挂画位置。 |
| 放大后方向键切换背后作品并关闭弹层 | 放大状态同步到 shell / reducer，隔离观展导航；放大层消费方向键。浏览器检查弹层保持打开、作品编号及 URL 不变，关闭后焦点恢复且导航可继续。 |
| 图片失败时仍记录“首作品可见 / 可操作” | 计时等待真实图片解码、有限转场结束及绘制完成；失败和暂扣图片均不产生标记，重试成功后只记录一次。前言阶段预载首图。 |
| 转场未结束就解除导航锁 | 使用实际动画结束信号，保留快速导航的单步队列；不再固定 360 ms 提前截断不同转场。 |
| 首次流式加载的长等待提示依赖尚未就绪的交互初始化 | 10 秒提示和 20 秒重试入口可在交互初始化前显示；重试采用原生链接。30 秒服务器延迟注入验证了提示、退出和重试成功。 |
| 服务器失败后的重试未重新请求数据 | 同时刷新路由和复位错误边界；故障注入解除后，可经原按钮重新进入展厅。 |
| 放大层短暂创建第二个渲染器、退出后的异步加载尚未取消 | 放大时同一更新先停用房间渲染器；引入加载取消与幂等释放。连续切换、隐藏和重新进入的资源测试见下文。 |
| 主叙事混入超长标题、采集评分说明和不一致场景 | 体验前言使用实际可展示数量及第一件所在场景；完整标题保留在展签 / 详情；caption 排除采集评分说明，缺少公开描述时使用已知年代 / 媒材。单元测试覆盖长标题、长输入和剔除记录。 |
| 画面上重复覆盖标题、环境音按钮覆盖房间编号 | 去掉画面上的重复图注，为顶部音频控制保留空间；桌面及手机截图已刷新并检查。 |

### 资源验证的实际范围

- `experience-boundaries.spec.ts` 验证有效深度图、错误深度图、WebGL 不可用及真实 `WEBGL_lose_context` 事件后的静态退路。
- `experience-resources.spec.ts` 连续前后切换 20 次、打开放大层、注入页面隐藏信号、卸载 / 重挂 3 次；实测活动 WebGL program 峰值不超过 1，卸载后 program、texture、待执行 RAF 均为 0，无未捕获异常。
- 音频测试真实加载本地 MP3，并确认播放时间前进、拒播后可重试、转场不叠音、静音 / 隐藏 / 卸载后停止并释放媒体源。此结果不代替实听音质和音轨授权核实。
- 深度图为测试专用的合成灰度 PNG，用于验证渲染分支。正式 release 仍无深度图；没有把合成测试图或原型估算图写进正式馆藏。
- 延迟 / 错误 / 合成深度样本由 E2E 启动器临时挂载，复用真实页面、loading 和 error 组件；测试结束后删除。生产构建路由表已确认不包含该测试入口。
- 页面隐藏通过浏览器事件注入；真实手机后台切换、实际触摸设备、读屏及原生浏览器 200% 缩放仍待验收。

### 五轮生产构建性能对照

2026-10-02 在同一台 macOS、Chromium、1440×900 视口、本地 `next start` 服务下测试；query 与 release 固定为上述基线。每轮创建新的浏览器上下文，浏览器缓存为空，服务端代码 / 数据先预热。每种路径各 5 次，保留[原始测量数据](../assets/experience-integration-acceptance/performance.json)。

| 路径 | 首件可见中位数 / 最慢 | 首件可操作中位数 / 最慢 |
| --- | --- | --- |
| classic | 991 / 1496 ms | 991 / 1496 ms |
| experience，立即跳过前言 | 1045 / 1100 ms | 1045 / 1100 ms |
| experience，前言完整显示后继续 | 2950 / 3139 ms | 2950 / 3139 ms |

起点为实际表单提交，终点等待真实图片解码、画框及祖先的有限动画结束，并检查下一件按钮可命中。两项指标恰好在同一帧满足；不是直接复用原先进入 Walk 即记时的标记。默认前言路径按“全部文字出现后立即点继续”测量，不代表人的实际阅读时间。

跳过前言的可操作中位数增加 **54 ms**，小于已确认的 **500 ms** 预算，性能门槛通过。此结果限于上述本地桌面环境，不代替弱网或手机性能。

当前测量脚本已随入口变更调整为 classic / 直接进入画作两条路径，运行方式见 2026-10-03 的说明；本节三个路径的数据仅作为历史基线保留。可通过 `ARTDUO_PERFORMANCE_URL` 指定另一生产服务。
