# 前端连续性修整 · 2026-10-28

用户已批准按综合评审的其余优先级实施、自测、commit push 和同步公网；本文件明确本轮模块与验收，不重新发起同范围审批。

## 已确认的边界

- 人物雕塑是独立彩蛋，不将其按绘画中的人物题材排除；综合报告第 1 项的收紧建议不实施。移除原有人物题材排除对彩蛋的影响，明确不看雕塑或限定媒介的条件沿用。18 件池、50% 机会、单次机会、原路线续接保持现状。
- 保留当前首页、五秒翻牌、明暗、透明底线输入、玻璃按钮、背景和随动强度、静观/边缘唤回。不给首页加文案或层级。
- 原展览快照、作品 ID、顺序保存格式、讲解按需请求、手写服务与公网拓扑保持原架构。

## 模块与接口

| 模块 | 实施内容 | 关键接口/不变项 |
| --- | --- | --- |
| `Plaque` / 阅读图片准备 | 原展签范围内即时显示打开/取消状态，图片失败或等待超时后仍可读文字，取消与卸载抑制迟到结果 | `expanded` / `onToggle`、原生 dialog 和真实图片解码继续使用；准备逻辑可取消并有时间上限 |
| 资料页与入口/恢复 | 将资料跳转准确命名；减少重复标题/返回动作，让讲解入口含义清楚；默认恢复保留原句并回新版入口 | 不自动生成讲解；既有 `returnTo`、`curationId`、`route`、作品位置不丢失 |
| 路线辅助页 | 无愿望时回新版入口；既有带愿望路线仍可打开，以本次已选作品的概览替换重复表单、版本和房间介绍；共享展厅的简短等待状态 | 保留 `/gallery` 与旧链接、顺序和位置兼容，不改策展/馆藏模块 |
| 观看设置 | 用顺序语义描述冻结选集重排；通用“画面轻动”与手机感应授权分开命名 | 不改作品集合；`useRoomMotion` 区分系统减少动态与用户总开关，让手机入口的禁用原因可辨认 |
| 近看 | 顶部按钮接入现有玻璃规则，触区至少 44px；返回约 200ms，Escape 立即退出，处理入场与退出计时竞态 | 保留空间入场、原位焦点恢复、深度渲染与较小随动幅度 |

## 验收与交付

1. 阅读准备的成功、失败、超时、取消有确定性回归；浏览器核对即时状态、文字兜底与取消后无迟到弹层。
2. 手机和桌面核对首页、阅读/资料/原位返回、设置、近看快速进退与减少动态；现有重排与导航回归继续通过。
3. 类型检查、相关现有测试及生产构建通过；使用既有回放验证，不以重新策展替代原链接恢复。
4. 在腾讯新发布目录独立构建并预检，保留当前运行版本与持久状态；上线后检查两个域名、静态资源、既有展览和手写可用性。
5. 仅提交本轮代码、评审/实施/验证文档；工作区原有无关改动不纳入。提交推送到现有分支，不新建分支或工作树。

导航再发现仍是待用户试验的风险，本轮保留已确认策略，不添加一次性提示。实体手机感应、Safari 实机与低端设备性能若无实际设备证据，仍明确记为未验证。
