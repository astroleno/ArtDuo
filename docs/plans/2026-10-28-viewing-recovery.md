# 观看恢复修整 · 2026-10-28

用户已批准按[全讨论综合评审](../reviews/artduo-frontend-consolidated-review-2026-10-28.md)开始迭代、commit、push 和同步腾讯云。沿用当前分支和单实例双域名架构。

## 模块与接口

- `ImageLightbox` / `ImmersiveDetailStage`：预览准备有超时及明确失败态，保留已显示图与署名；原位重试，取消或关闭时通过 `LIGHTBOX_RESTORE` 恢复可见作品的位置，清掉待导航。高清失败保留预览。
- 阅读 / 近看共用一个小型浏览器历史控制器。打开时仅增加一个临时层记录；浏览器 Back 先收起，主动关闭与 Escape 消费同一记录。换画替换 URL 时保留 Next 和临时层状态，退层同步最新作品地址。已关闭记录在前进时跳过，刷新遗留记录收敛回普通展厅；导航到资料页不被退层操作拉回。
- `Plaque` / 阅读 CSS：保持图片就绪或五秒兜底后开层；失败后使用紧凑且固定的参照区域，提供原地重试。重试不重挂正文，不移动阅读位置；成功后仍用该紧凑区域，重开阅读恢复正常布局。
- `contracts` 共享绘画媒介词表，服务端观看意图与 UI 雕塑资格共同使用。补全明确否定和中英文限定，明确欢迎雕塑的开放愿望不被误排除；人物题材规则不变。不修改作品池、概率、存储格式和策展接口。
