# 观看反馈与展厅迭代

2026-10-09。用户批准上一轮讨论方案，并要求测试后 commit / push；沿用当前分支，主线程执行。

## 目标与模块接口

1. 精选可靠正面展墙，保持阶段内空间连续；画框按绘画 / 纸本处理，原作不加滤镜。小展签与独立阅读层分离，手机阅读不再挤压画作布局。
2. 在原始选集与硬性排除约束内，按具体题材、色彩和构图线索改善相邻作品的联系；平静意图不被强制升级为强刺激阶段。
3. `ViewerObservation` 记录可见且解码后的有效观看、放大、回看和导航；不记录视线、传感器或推测的情绪。普通观看、放大和阅读分开计时，后台 / 加载失败暂停。有限的节奏倾向至少参考多件作品，不自动改变选画方向。
4. `ViewingPreference` 接收“更安静 / 多看这类 / 换一种题材 / 保持原路线”的明确反馈；`RouteRevision` 只调整尚未经过的尾部，冻结已走过的前缀和当前作品。反馈在下一次前进到未看部分时生效，可取消待应用操作，也可恢复剩余部分的原始顺序。
5. UI 包负责纯会话状态与策略、观看计时、会话存储；web adapter 提供稳定的作品单元 ID 与展厅安排；web URL 层保留经过验证的作品排列。继续使用现有 `GrowthForm` 作为初始策展，不增加服务端埋点数据库或远程重排 API。
6. 会话记录只写 sessionStorage，限制长度并校验版本与作品集合，存储失败时仍可内存浏览。URL 的 `route` 参数仅允许原始合格选集的完整排列，供刷新、详情返回及复制链接恢复顺序；不包含观看记录。音频由用户开启，阅读时降低音量，保持原速。

## 核心不变量

- 作品身份不依赖排名；重排不增删原始合格选集，不放宽排除条件。
- 已访问的前缀、当前作品和回看方向不随重排改变；在回看位置提出的反馈延迟到走回未看边界。
- 修改下一段路线不会在当前画面触发场景或图像替换。连续反馈只保留一个待应用决定。
- 已访问作品保留当时的场景；未看作品承接目标位置的阶段与场景。
- 撤销仅恢复未访问的后续部分，不改写已经走过的顺序；无匹配、信号不足、非法 URL 或会话数据损坏均保留可用路线。
- 阅读层具有焦点管理、Escape 关闭及触发器焦点恢复；原作像素不接受情绪滤镜。
