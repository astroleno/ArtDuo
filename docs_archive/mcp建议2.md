你的这份 TODO 作为“把 MCP 真接入 + 提升数据质量”的施工单是合理的，尤其是去 Mock、结构化校验、溯源与去重、child\_process 安全、可观测性等关键环节都覆盖到了。要把它扩展成“完整的 LLM + MCP 联动，并能产出**个性化但无记忆（stateless）**的沉浸式策展”，还需要在**上层编排与叙事产出**补齐几个能力层。下面给出差距评估与可直接并入的新增条目。

# 结论

* 现有 TODO = “数据管线可靠性 + 安全 + 质量”已基本到位。
* 仍缺 = “检索编排（多源/多策略）→ 重排与多样性约束 → 策展叙事生成 → 视觉/色谱联动 → 运行时体验与合规模块”。
* 保持无状态：所有“个性化”都从**当前输入与当次检索上下文**推导，不落库用户画像；仅用会话级临时状态与缓存。

# 必需新增模块（按落地优先级）

## 1) 查询理解与情绪语义层

**目标**：把“情绪/自然语言”稳定映射到可检索的多路关键词与视觉线索（颜色、材质、时代、流派）。

* 情绪→关键词映射表（含权重与同义词、跨语言；Plutchik/Valence-Arousal 二维为底盘）。
* 颜色/材质/主题词抽取：从输入中抽“色相/冷暖/饱和”“自然/都市/宗教/肖像”等检索子维度。
* 违规/低质量输入护栏：空输入、仅停用词、过短文本→提示重写或给候选模板。
* 可控随机种子：为本次会话生成 `seed`，所有抽样/洗牌基于 seed，保证**可复现且无记忆**。

## 2) 检索编排与多源路由

**目标**：不依赖单一馆藏；跨源召回并做统一规范化。

* SourceAdapter：Met、Tate、Rijks、GA\&C/IIIF 支持；统一 ArtworkSchema（你已有初版）。
* 路由策略：按题材/年代/开放许可可用性对不同源加权；失败快速切换。
* 成本与时延：并行批量请求 + 超时与退避；命中一组即可进入重排，后续增量补齐。

## 3) 重排评分与多样性约束

**目标**：既相关，又有“展线节奏”。

* 基础分：文本相关（关键词 BM25/TF-IDF 或小向量语义相似度）× 许可可用性（CC0 优先）× 图像清晰度/尺寸阈值。
* 多样性约束：时期、流派、地域、媒介、性别/族裔代表性（如可得）做 Maximal Marginal Relevance（MMR）。
* 视觉一致性：与情绪色谱的色相/明度差评估，剔除极端冲突件或将其放在“转折段落”。
* 9 件套编曲器：1-9 位点位规则（起-承-转-合），可配置为“平缓/对比/波动”三种曲线模板。

## 4) 策展叙事与展签生成（LLM 可控输出）

**目标**：从“9 件作品 + 分数/理由”产出完整展线文本与“为什么在这里”。

* JSON 契约（强 Schema）：

  * `exhibition_title`, `curatorial_statement`（200-300字）
  * `sections[]`：每节包含 `mood`, `transition_text`, `items[ {id, why_here(<=80字), wall_label(<=120字), keywords[]} ]`
  * `palette`：主色、辅助色、背景光强指标
* 提示词硬约束：逐条条款 + 例子 + 反例，禁止幻造来源；只许使用传入字段。
* 审计器：生成后自动校验 JSON 与字数/字符集/占位检查；失败自动重试。

## 5) 视觉/色谱联动与布局策略

**目标**：页面氛围与展线同频。

* 情绪色谱映射：情绪→`hue/sat/lum` 与光锥半径；生成页面背景渐变与 Spotlight 强度。
* 布局模板：三种展线布局（直线、折返、对称），依据“曲线模板”选择。
* 图片占位与比例：按作品画幅比例自适应卡片，边框与标题样式跟随色谱。

## 6) 运行时体验（Stateless 友好）

**目标**：不存个体画像，仍给“像为我而设”的感觉。

* 会话级 `sessionId` + `seed`；一切决策与动画从种子推导，可复现。
* 渐进式呈现：

  * T0：先出展名+氛围背景
  * T0+0.8s：出 1/3 件“锚点”作品卡（高分）
  * T0+1.5s：补全余下作品与“转场文字”
* 部分失败降级：某一源失败不打断展线；在卡片角标显示“来源暂不可用，已替换”。

## 7) 合规与版权

**目标**：可商用的安全默认。

* 过滤非开放许可或无清晰图的大图；展示 `rights`、`museum`、`objectUrl`。
* 图像代理与裁剪：自托管 Thumb/CDN，加 Referer/缓存策略，尊重源站条款。
* 明确署名规范：统一落在卡片与详情页。

## 8) 性能与韧性

* 批量化：IIIF `?region/size` 一次性取适配尺寸；首屏只取 `w=800`，进场后懒加载大图。
* 断路器：MCP 多次错误→短暂熔断并切换备源。
* 端到端预算：首交互 < 1.5s（有骨架屏），完整展线 < 6-8s；动画 60fps。

## 9) 监控与验收

* 指标补充：`vector_fallback_rate`、`license_block_rate`、`mmr_diversity_score`、`palette_conflict_rate`。
* 金丝雀用例：固定 6 组情绪词，日巡检对比“来源分布/多样性/许可通过率”。
