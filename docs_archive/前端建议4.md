1. 极简渐变背景（最安全）

色彩：深灰 → 高级蓝 / 高级墨绿 的低饱和度渐变。

感觉：像美术馆里有质感的灰色墙面，在光影下有微妙层次。

实现：CSS linear-gradient + 轻微 noise texture，避免“平板感”。

适合场景：大部分现代艺术馆（MoMA、泰特现代）常用这种做法。
👉 优点：稳重、简洁、永不过时。

2. 灯光投射式背景（更有氛围）

色彩：深色底 + 圆形光晕（中心偏亮，四周渐暗）。

感觉：像画廊打光，把墙中央“照亮”，让观者的注意力自然聚焦。

实现：CSS Radial Gradient / Three.js shader 模拟 spotlight。

适合场景：当你希望“输入框/主标题”像被 spotlight 打亮时。
👉 优点：立刻拉出“展厅感”，但要避免过度戏剧化。

3. 纹理质感背景（增加真实感）

材质感：细腻的亚麻布、纸张肌理、灰泥墙。

感觉：给人真实墙面质感，比纯色更有“艺术馆温度”。

实现：高分辨率 subtle texture 叠加低透明度，或者 Procedural Noise Shader。

适合场景：想营造“精品画廊”或“日本/北欧极简美学”的时候。
👉 优点：高级、细腻，缺点是需要谨慎压缩贴图体积。

4. 动态呼吸背景（强调情绪感）

表现：背景色调会随用户输入的情绪轻微变化，比如「孤独」→ 蓝灰呼吸渐变，「喜悦」→ 金色柔光律动。

实现：Canvas Shader / WebGL 动态渐变 + easing（慢速呼吸感，不要快节奏）。

适合场景：强调“AI根据情绪生成氛围”，呼应你的“情绪展厅”理念。
👉 优点：独特而有记忆点，但一定要慢、轻，避免成“炫酷科技感”。

5. 纯白极简背景（风险较高）

效果：像当代艺术馆的白盒子空间（White Cube）。

感觉：冷静、克制，艺术作品会最突出。

缺点：网页环境下容易显得“空”，缺乏氛围感，尤其是没有作品时会很寡淡。
👉 除非你有大量高质量艺术品展示，否则不推荐。

🎯 推荐组合

主背景：极简深灰/深蓝渐变（#1）

核心区域：局部 Spotlight 光晕（#2）

细节增强：轻微亚麻/纸纹理叠加（#3）

加分体验：随情绪微变的动态呼吸色彩（#4）

这样就能做到 既像真实画廊，又有数字艺术的独特感。
