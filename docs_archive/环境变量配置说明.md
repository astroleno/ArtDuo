# ArtDuo 环境变量配置说明

## 🔑 API密钥配置问题

### 问题描述
根据[Rijksmuseum API文档](https://data.rijksmuseum.nl/docs)和代码分析，发现了API密钥配置问题：

1. **环境变量前缀错误**: 在Next.js中，客户端环境变量需要`NEXT_PUBLIC_`前缀
2. **环境变量文件缺失**: 项目中没有`.env.local`文件
3. **API端点配置**: 需要确认正确的API端点

### 当前配置状态
- **API密钥**: `YlOP5cOT` ✅ 有效
- **环境变量名**: `RIJKS_API_KEY` ❌ 错误（应该是`NEXT_PUBLIC_RIJKS_API_KEY`）
- **环境变量文件**: 缺失 ❌

## 🛠️ 解决方案

### 1. 创建环境变量文件
在`frontend/`目录下创建`.env.local`文件：

```bash
# ArtDuo 环境变量配置
# 注意：在Next.js中，客户端环境变量需要NEXT_PUBLIC_前缀

# Rijksmuseum API 配置
NEXT_PUBLIC_RIJKS_API_KEY=YlOP5cOT
NEXT_PUBLIC_RIJKS_API_URL=https://www.rijksmuseum.nl/api/nl/collection

# OpenAI/BigModel 配置
NEXT_PUBLIC_OPENAI_API_KEY=6be0ec1133ba4e9fb16b5ed76ae9f3fc.JEf38PO0DQiorzxl
NEXT_PUBLIC_OPENAI_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions

# Met Museum API 配置
NEXT_PUBLIC_MET_API_URL=https://collectionapi.metmuseum.org/public/collection/v1

# 应用配置
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 2. 代码修复
已修复`rijksmuseum-api.ts`中的环境变量读取：

```typescript
// 修复前
this.apiKey = process.env.RIJKS_API_KEY || '';

// 修复后
this.apiKey = process.env.NEXT_PUBLIC_RIJKS_API_KEY || '';
```

### 3. 验证配置
重启开发服务器后，检查控制台输出：
```
🔑 Rijks API 密钥状态: 已配置
```

## 📚 Rijksmuseum API 文档参考

根据[官方文档](https://data.rijksmuseum.nl/docs)，Rijksmuseum提供以下API服务：

### 1. REST API (已弃用)
- **状态**: DEPRECATED
- **端点**: `https://www.rijksmuseum.nl/api/nl/collection`
- **说明**: 当前代码使用的端点，但已被标记为弃用

### 2. 新的数据服务API
- **OAI-PMH API**: 用于批量数据获取
- **LDES API**: 用于实时数据流
- **IIIF API**: 用于图像服务

### 3. 建议的API使用方式
```typescript
// 当前使用的搜索API
const searchUrl = `${this.searchBaseUrl}?key=${this.apiKey}&q=${query}&imgonly=true`;

// 获取作品详情的API
const detailUrl = `${this.searchBaseUrl}/${id}?key=${this.apiKey}`;
```

## ⚠️ 注意事项

1. **安全性**: `.env.local`文件包含敏感信息，不要提交到Git
2. **部署**: 在Vercel等平台部署时，需要在控制台设置环境变量
3. **API限制**: Rijksmuseum API可能有请求频率限制
4. **备用方案**: 如果Rijksmuseum API不可用，系统会回退到Met Museum API
