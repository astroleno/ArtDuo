# ArtDuo 策展流程设计文档

## 完整策展流程

### 1. 用户输入阶段
- **页面**: `首页 (page.html)`
- **功能**: 用户输入情绪描述
- **跳转**: `/gallery/immersive?emotion=用户输入`

### 2. 沉浸式页面策展阶段
- **页面**: `沉浸式页面 (gallery/immersive/page.html)`
- **功能**: 在沉浸式页面中处理整个策展流程

#### 2.1 策展启动阶段
- **步骤1**: 检查localStorage是否有策展数据
- **步骤2**: 如果没有数据，启动策展流程
- **步骤3**: 显示"正在策展中..."状态

#### 2.2 非SSE处理阶段
- **步骤1**: 大模型解析语义并做策展策略
- **步骤2**: API搜索艺术作品
- **步骤3**: 返回结果粗筛+LLM打分
- **步骤4**: 设计情绪曲线（SSE）

#### 2.3 SSE流式处理阶段
- **步骤5**: 选择9幅最合适的作品（SSE）
- **步骤6**: 生成前言+结语（SSE）
- **步骤7**: 3+3+3模式生成作品讲解（SSE）

### 3. 沉浸式体验展示
- **页面**: `沉浸式页面 (gallery/immersive/page.html)`
- **功能**: 沉浸式艺术体验

#### 3.1 序言展示阶段
- **流式输出序言**: 用户看到序言逐步生成
- **序言阅读**: 用户阅读完整序言
- **开始浏览**: 序言完成后用户可开始浏览作品

#### 3.2 作品浏览阶段
- **显示全部9张作品**
- **前3张**: 有完整讲解，用户可立即浏览
- **后6张**: 讲解在后台3+3+3模式生成
- **实时更新**: 通过SSE流式更新讲解

#### 3.3 结语展示阶段
- **结语生成**: 后台生成策展结语
- **跳转准备**: 结语完成后准备跳转到画廊页面

### 4. 画廊页面（回顾功能）
- **页面**: `画廊页面 (gallery/page.html)`
- **功能**: 结语后的完整作品回顾
- **显示内容**: 完整9张作品，所有讲解已完成
- **沉浸式按钮**: 可重新进入沉浸式模式

## 技术实现细节

### 时间控制机制
```javascript
// 沉浸式页面 - 序言流式输出
case 'introduction':
    this.showIntroductionStreaming();
    break;

// 沉浸式页面 - 序言完成后允许浏览
function showIntroductionStreaming() {
    // 流式显示序言，完成后允许浏览
    this.streamIntroductionText(introduction);
}

// 结语完成后跳转到画廊页面
case 'conclusion':
    setTimeout(() => {
        window.location.href = `/gallery?emotion=${encodeURIComponent(emotion)}`;
    }, 3000);
    break;
```

### 数据传递机制
- **SSE流式**: 沉浸式页面直接接收策展数据
- **实时更新**: 通过SSE事件流实时更新界面
- **localStorage**: 策展数据持久化备份
- **3+3+3模式**: 分批生成讲解，实时更新

### SSE事件处理
```javascript
// 策展API事件流
1. emotion_curve → 情绪曲线生成
2. artworks_selected → 9幅作品选择
3. introduction → 前言生成（触发15秒跳转）
4. conclusion → 结语生成
5. explanations_batch → 3+3+3讲解生成
6. complete → 策展完成
```

## 组件功能对应

### 首页 (page.html)
- **功能**: 情绪输入界面
- **主要组件**:
  - `HomePage` 类: 页面主控制器
  - `createFlipText()`: 翻转问题动画
  - `escapeLetter()`: 字符转义处理
  - 翻转问题显示、输入框、提交按钮
- **跳转**: 情绪参数传递到画廊页面

### 画廊页面 (gallery/page.html)
- **功能**: 策展流程处理
- **主要组件**:
  - `GalleryPage` 类: 画廊页面主控制器
  - `callCurationAPI()`: 调用策展API
  - `handleCurationEvent()`: 处理SSE事件流
  - `showCurationIntroductionAndNavigate()`: 显示序言并跳转
  - `continueBackgroundCuration()`: 后台继续策展
  - `renderArtworks()`: 渲染艺术作品
  - `updateLoadingText()`: 更新加载状态
- **职责**: 处理完整策展流程，数据传递

### 沉浸式页面 (gallery/immersive/page.html)
- **功能**: 沉浸式艺术体验
- **主要组件**:
  - `ImmersiveGallery` 类: 沉浸式画廊主控制器
  - `loadCurationData()`: 加载策展数据
  - `updateImmersiveGallery()`: 更新沉浸式画廊
  - `startBackgroundLoading()`: 后台加载监听
  - `ArtworkDisplay`: 艺术作品展示组件
  - `ControlButtons`: 控制按钮组件
  - `DetailedAnalysis`: 详细分析组件
  - `ModernArtworkCard`: 现代艺术作品卡片
  - `ModernControlPanel`: 现代控制面板
  - `ModernProgressBar`: 现代进度条
  - `NavigationButtons`: 导航按钮
  - `ProgressIndicator`: 进度指示器
- **职责**: 展示策展结果，提供沉浸式体验

| 组件名称 | 功能描述 | 数据来源 | 更新方式 |
|---------|---------|---------|---------|

| `startBackgroundLoading()` | 后台加载监听 | localStorage轮询 | 每2秒检查一次 |

| 组件名称 | 功能描述 | 显示内容 | 触发时机 |

## 用户体验设计

### 时间节点
- **0秒**: 用户输入情绪，直接跳转到沉浸式页面
- **2秒**: 沉浸式页面启动策展流程，显示"正在策展中..."
- **5秒**: 大模型解析语义并做策展策略
- **10秒**: API搜索艺术作品
- **15秒**: 返回结果粗筛+LLM打分
- **20秒**: 设计情绪曲线（SSE开始）
- **25秒**: 选择9幅最合适的作品（SSE）
- **30秒**: 序言流式输出，用户看到序言逐步生成
- **35秒**: 序言完成，用户开始浏览前3幅画
- **后台**: 继续生成剩余6幅讲解和结语
- **结语完成**: 3秒后跳转到画廊页面进行完整回顾

### 流程执行步骤

#### 阶段1: 页面跳转和策展启动（0秒到2秒）
- **用户输入**: 情绪描述提交
- **直接跳转**: 跳转到沉浸式页面
- **策展启动**: 沉浸式页面启动策展流程
- **状态显示**: 显示"正在策展中..."

#### 阶段2: 非SSE处理（2秒到20秒）
- **语义解析**: 大模型解析情绪并制定策展策略
- **API搜索**: 调用艺术作品搜索API
- **粗筛评分**: 返回结果粗筛+LLM打分
- **情绪曲线**: 设计情绪曲线（SSE开始）

#### 阶段3: SSE流式处理（20秒到30秒）
- **作品选择**: 选择9幅最合适的作品（SSE）
- **序言生成**: 生成前言+结语（SSE）
- **流式输出**: 用户看到序言逐步生成

#### 阶段4: 沉浸式体验（30秒后）
- **序言完成**: 序言流式输出完成
- **开始浏览**: 用户可开始浏览前3幅画
- **后台处理**: 继续生成剩余6幅讲解和结语
- **实时更新**: 通过SSE流式更新讲解内容

#### 阶段5: 结语和回顾（结语完成后）
- **结语生成**: 后台生成策展结语
- **跳转准备**: 3秒后跳转到画廊页面
- **完整回顾**: 画廊页面显示完整策展结果

### 交互流程
1. **直接跳转**: 主页直接跳转到沉浸式页面
2. **流式体验**: 序言流式输出，用户看到逐步生成过程
3. **沉浸浏览**: 序言完成后开始浏览艺术作品
4. **渐进加载**: 后台继续生成剩余讲解和结语
5. **完整回顾**: 结语后跳转到画廊页面进行完整回顾

### 数据流
```
首页 → 沉浸式页面 → 策展API → 沉浸式体验 → 画廊页面
  ↓         ↓         ↓         ↓         ↓
情绪输入   策展处理   SSE流式   沉浸体验   完整回顾
```

## 技术架构

### 前端架构
- **页面路由**: Next.js App Router
- **数据传递**: SSE流式 + localStorage备份
- **事件处理**: 沉浸式页面直接处理SSE事件
- **状态管理**: 策展数据实时更新

### 后端架构
- **策展API**: `/api/curate/stream`
- **SSE流式**: 实时数据推送
- **数据缓存**: 策展结果缓存
- **性能优化**: 3+3+3分批处理
