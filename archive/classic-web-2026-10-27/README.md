# 已归档的经典入口与展厅

2026-10-27，用户确认两个域名的 `/ArtDuo` 默认进入新版，旧版不再作为公开模式提供。

这里按原路径保存切换前的首页、经典展厅、模式选择器和浏览器回归源码。每个文件增加 `.txt` 后缀，作为只读历史资料，不参与应用编译或测试发现。来源提交和逐文件指纹见 `manifest.json`。

公开入口统一使用新版；旧 `view=classic` 地址仍可打开，并以新版恢复原来的观看愿望、馆藏版本、策展记录和作品位置。归档不删除已保存的展览、图片、额度或手写卡。共享的绘画查看、深度与场景工具仍由当前应用复用，不随旧入口一起移除。

恢复历史实现时，应从记录的 Git 提交或这些文件取回完整版本，不能只恢复旧首页并混用当前路由逻辑。服务器的上一发布目录和持久数据备份另行保留，依照部署文档回滚。
