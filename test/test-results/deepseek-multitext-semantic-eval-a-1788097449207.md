## 更严格来源绑定是否有效

有效，而且不是长度硬通过造成的假象。v3 的 hard pass 反而最低，但语义分和事实分最高，严重错误率最低。具体修复包括：

- 夜景结语五轮均不再补街灯、建筑、光影质感或人物故事。
- 残缺档案五轮均未再擅造保存、流转或自然损坏原因。
- 修补前言四轮满分，一轮仅因过短和行政化扣分，没有再补使用史、修补效果或物件历程。

未完全修复的是纪念结语：模型仍会在篇幅压力下从“登记为纪念用途”滑向“观众应感受纪念意义”。

## 约 700 input tokens 是否值得

结论是有条件值得。

如果 framing 用于馆藏、展览或其他高事实风险场景，额外 tokens 换来的严重错误率下降具有明确价值，建议使用 v3。若按单纯“每 token 得分”衡量，v3 并不经济：输入约为 v1 的 2.18 倍，却只增加 1.87 分；因此不应无差别用于其他类别。

建议只把 v3 路由给 framing_text，并把提示词压缩到 500 tokens 以内，同时保留以下约束：

1. 正文补足长度时，只能复述已给元数据和缺项，禁止添加视觉、历史或意义词。
2. 纪念结语不得要求观众感受纪念意义，也不得预设疗愈、释然或精神结果。
3. 删除重复的“按现有信息呈现、保留未知部分”说明，改善自然度。
4. 压缩后继续跑五轮；严重错误率不得高于 5%，正文长度通过率应提升到 90% 以上。
