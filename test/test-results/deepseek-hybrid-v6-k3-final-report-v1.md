# DeepSeek Hybrid-v6 × K3-256k 流式 Eval

## 结论

**hybrid-v6 的推荐方向有效，但整套框架仍不冻结。** 与 v5 相比，DeepSeek 单文本双评均分提高 **1.314/20**，严重错误率下降 **15.6 个百分点**；combined 前言/结语提高 **4.175/20**，严重错误率从 **75% 降到 15%**。这说明风险 profile、共享事实表和 unknown-state 护栏确实改善了语义质量。

但预注册 gate 仍为 `hold`：单文本均分只有 17.704、严重错误率 17.2%、距 K3 1.921 分；v6 单文本和 combined 叙事的输入 tokens 分别增加 51.2% 和 64.8%。目前适合保留为候选的是作品介绍和 combined-guarded 叙事，不适合统一切换或改生产代码。

本轮共完成 **188 次流式请求**：DeepSeek 168 次、K3-256k 20 次。全部 HTTP 200、全部收到首个文本、全部解析为约定 JSON、没有重试。DeepSeek thinking 字符为 0；K3-256k 开启 4096 thinking budget，20 次均返回 thinking。两位独立评估员各盲评 188 条，共 376 条逐项评分。

## DeepSeek 单文本：v5 与 hybrid-v6

16 个新未见 case，覆盖情感理解、作品介绍、前言、结语和策展分析；每个 variant 每个 case 跑四轮，共 128 次请求。

| 指标 | generic-task-routed-v5 | recommended-hybrid-v6 | v6 变化 |
|---|---:|---:|---:|
| 样本 | 64 | 64 | — |
| 平均输入 tokens | 350.25 | 529.75 | **+51.2%** |
| 平均输出 tokens | 107.05 | 107.41 | +0.3% |
| TTFT 中位数 | 605 ms | 617 ms | +2.0% |
| 总时间中位数 | 1586.5 ms | 1602.5 ms | +1.0% |
| JSON 可用率 | 100% | 100% | 持平 |
| deterministic hard pass | 79.7% | 79.7% | 持平 |
| 核心证据覆盖 | 92.2% | 95.9% | +3.7pp |
| 双评估员均分 /20 | **16.390** | **17.704** | **+1.314** |
| 双评估员严重错误率 | 32.8% | 17.2% | **-15.6pp** |

v6 的质量收益不是 hard pass 或输出长度造成的：hard pass 持平、输出 tokens 基本不变，而证据忠实和语义边界评分提高。代价主要来自输入提示词变长；本批 TTFT 只慢 12ms，总时间只慢 16ms，但输入成本超过预注册的 25% 上限。

残留错误高度集中：

- 情感：偶发把用户的“高兴/不确定”写成助手自身感受，或给并存情绪补因果。
- 可达性策展：把“八岁外甥、拄手杖的叔叔”改写为幼童、长者、低刺激或行动辅助需求，并补屏幕注视、轮椅等条件。
- 前言/结语：仍会把收据、底片盒、信封、样本袋包装成“时间痕迹、历史见证、沉默、等待、秘密、背后故事、留给想象”。
- unknown-state：偶尔把“资料未记录种子是否仍在袋内”强化成种子缺失、后续命运或保存结果。

作品介绍最接近目标：v6 双评 19.314，与 K3 只差 0.436，四类证据状态的平均严重错误率约 3.1%。

## 下一轮建议

1. 情感：增加不可变的说话者映射，用户状态只能用“你/用户”，助手回应只能用“我会/我不”；禁止把用户情绪写成助手感受。
2. 无障碍：锁定年龄、亲属称谓、手杖和环境要求的字段角色；不允许转换成幼童、长者、能力标签、疾病或其他辅具。
3. Framing：把“时间痕迹、历史见证、沉默、等待、秘密、故事、想象、命运”等设为无证据即拒写的高风险词，并在输出后做确定性扫描。
4. Unknown-state：只有 `explicit_absences` 可写成空白/不存在，其余统一保留“资料未记录/无法确认”，禁止同义强化。
5. 压缩：按 task/risk profile 只发送相关护栏，删除跨任务通用长规则，把 51–65% 的输入增长压到 25% 内。

当前最合理的落点是：**作品介绍采用 v6 候选；前言与结语继续 combined，并以 guarded-v6 为质量候选；情感、可达性策展和 framing 再做一轮 v6.1 窄迭代。整套 hybrid-v6 暂不进入生产。**
