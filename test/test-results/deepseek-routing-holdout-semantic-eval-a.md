# DeepSeek routing holdout 独立语义盲评（Evaluator A）

## 结论

在 16 个完全未见 case、128 条输出上，generic-task-routed-v5 总体优于 source-isolated-v3：均分 **17.891 vs 17.172（+0.719）**，严重错误率 **20.31% vs 34.38%（-14.06 个百分点）**。

但 v5 的优势极不均匀。它显著改善 emotion、artwork introduction 和大部分 curation analysis，却使 exhibition preface 下降 3.0 分、exhibition closing 下降 5.25 分。尤其是声音转写状态与毕业织物结语，v5 把资料缺项扩成了“其余内容缺失”“历史见证”“纪念意涵”。因此 v5 不能整包替换 v3。

推荐混合路由：v5 用于 emotion、artwork 与大部分 curation；v3 保留 preface、closing；代际无障碍另设不推断能力的确定性模板。

先逐条读取并评分全部输出，之后才查看性能汇总。每条以 `row.reference` 中的 Codex Sol max 作为事实与任务功能参照，不按措辞相似度评分。五维各 0–4 分：证据忠实、任务功能、语义辨析、自然度、边界约束，总分 20。

## 主要质量差异

### v5 的可靠改进

- artwork 四个未见 case 达到 19.875，零严重错误；尤其解决了描述字段被当作真实画面的混淆。
- emotion 的严重错误由 4 条降到 1 条，隐私结果 case 不再虚构“压制情绪、拒绝安慰”。
- curation 的安静短访、无疗愈悲伤、明亮低对比三类明显改善，不再任意指定流派、作品题材与情绪高潮。

### v5 的阻断回退

- preface 把磨损说成“记录自身历史”，把目录卡写成历史载体、时间痕迹与思考对象。
- closing 把“只有一段完整转写”错误化为“其余转写缺失/内容无法还原”；把毕业用途登记扩成历史见证与纪念意涵。
- intergenerational access 四轮仍全部推断儿童和长者的认知负荷、注意力与媒介适配，违反“不推断能力”的明确边界。

## 最终建议

1. v5 用于 emotion_response 与 artwork_intro；赞誉后想哭增加“不得命名温暖、酸涩、喜悦”的白名单约束。
2. exhibition_preface 与 exhibition_closing 暂时保留 v3，不使用 v5。
3. curation_analysis 默认 v5，但 intergenerational_access 必须独立模板：只落实座位、连贯动线、短文本、无闪烁和约40分钟，不推断认知、注意力、疾病、感官或媒介偏好。
4. 对转写状态建立三值字段：完整 / 不完整 / 未说明；禁止由“一段完整”推出“其余缺失”。
5. 对登记用途与物理痕迹增加禁推规则，不得自动升级为历史见证、意义承载或时间痕迹。

按上述混合路由执行后，再做同 taskType 的未见验证；当前数据不支持整包冻结 v5。
