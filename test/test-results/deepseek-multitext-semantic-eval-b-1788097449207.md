# DeepSeek source-isolated-v3 framing 专项语义盲评（Evaluator B）

## 结论

v3 的约 700 input tokens 对 **framing 专项值得**。20 条五轮盲评均分为 **19.25/20**，事实依据 **3.80/4**，严重错误 **1/20（5%）**；相比 v1/v2 的严重错误率均为 50%，这不是单纯通过长度或格式约束，而是来源绑定、事实边界和语义忠实度的实质改善。

不建议把该长提示词无差别用于情感理解或作品阐释。残余风险集中在纪念物件结语：五轮中有一轮重新要求观众“感受纪念意义”，并滑向疗愈、释然等套话。

## 评估口径

逐条读取 DeepSeek 原文，并以每条 Codex Sol max 与 Kimi K3 max 双 golden 为参照。五个维度均为 0–4 分：instruction alignment、factual grounding、semantic fidelity、restraint and boundary、naturalness，总分 20。严重标记沿用上一轮口径。

## 是否只是 hard pass

不是。v3 的确定性 hard pass 只有 13/20（65%），但语义盲评均分仍为 19.25；部分字数或形式未完全命中的输出仍能准确守住记录事实和策展边界。真正的提升主要落在事实依据与克制边界，而非长度达标。

## 最终建议

将 source-isolated-v3 作为前言/结语 framing 路由的候选提示词，保留约 700 input tokens 的来源隔离设计；不要扩散到其他文本类别。

上线前为纪念类结语增加后置约束或检查：禁止要求观众“感受意义”，禁止“疗愈、释然、静默意义”等结果导向表达；只允许说明登记用途、资料缺项与观看选择。该 guard 可针对本轮唯一严重回退点，成本远低于继续整体加长提示词。
