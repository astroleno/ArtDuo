# DeepSeek routing holdout 独立语义评估 B

## 口径

- 样本：128 条未见输出，两个 variant 各 64 条；每个 case 四轮。
- 五维各 0–4：证据忠实、任务功能、语义辨析、自然度、边界约束。
- 参考答案只用于核对事实与任务目标，不按措辞相似度评分；性能指标不进入质量分。

## Case 波动

- v3 四轮分差均值 3.38，最大 7；6 个 case 分差至少 5。高波动集中在已知画面描述、描述冲突、两类情绪及策展分析。
- v5 四轮分差均值 1.50，最大 4，没有分差至少 5 的 case。
- v5 唯一仍出现严重错误的 case 是 `holdout_closing_voice_fragments`：3/4 轮把“仅一份完整转写”误推成“其余转写缺失”或“内容无法还原”。
- v5 的毕业织物结语均分 16.25、分差 4，虽无严重错误，但容易把“未记录”组织成偏强的历史叙事。

## 结论

建议有条件采用 v5：情绪回应、作品介绍、策展分析可以切换；展览前言与结语暂保留 v3 路由。统一切换前，应在结语规则中明确区分“只确认一份完整转写”和“其余均缺失”，并禁止把未知状态改写为缺页、空白、未还原或沉默。这样才能保住 v5 在其他任务上的真实增益，同时消除当前最集中的新回归。
