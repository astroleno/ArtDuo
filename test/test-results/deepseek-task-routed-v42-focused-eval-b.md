# Evaluator B：v4.2 三个风险 case 定向盲评

## 结论

v4.2 的修复是真实的，但三个 case 并未全部达到可直接采用水平。

- `emotion_apology_anger`：可采用。均分从 15.75 升至 18.375，严重错误从 4/8 降至 0/8。
- `preface_incomplete_archive`：可采用。均分从 15.875 升至 17.625，严重错误从 1/8 降至 0/8；不再把馆藏记录写成存世作品、实物或影像。
- `art_rich_contrast`：暂缓。均分从 14.375 升至 15.875，严重错误从 6/8 降至 3/8，但仍有猎人单复数错误和外部艺术史信息注入。

全量上，v4.2 从 15.3333 升至 17.2917，严重错误率从 45.83% 降至 12.50%。输入 token 增加 17.1%，但本批实际总延迟中位数下降 9.4%，成本可以接受。

## Case 修复与稳定性

| Case | v4 均分 / 极差 / 严重轮 | v4.2 均分 / 极差 / 严重轮 | 判断 |
|---|---:|---:|---:|
| emotion_apology_anger | 15.750 / 6 / 4 | 18.375 / 3 / 0 | 真实修复，可采用 |
| art_rich_contrast | 14.375 / 9 / 6 | 15.875 / 5 / 3 | 部分修复，暂缓 |
| preface_incomplete_archive | 15.875 / 8 / 1 | 17.625 / 3 / 0 | 真实修复，可采用 |

### 道歉后更生气

v4 会写成“你道歉后”、补出“终于道歉”，或把先后关系直接解释成“因为道歉而生气”。v4.2 八轮均未再补等待经历或明确因果，道歉者角色也不再稳定倒置。

剩余问题属于轻度表达质量：一轮写成“你的道歉来了”，主语略含混；一轮写出“更生的气”，明显不自然，但均未形成新的事实经历。

### 诗画反差

v4.2 确实清除了大面积的“可能归于北斋”“记录日期非制作日期”等路由字段串线，但来源纯度仍未修完：

- 第 6 轮把复数猎人改成“一位猎人”。
- 第 1 轮增加“日本艺术家”，第 8 轮增加“日本浮世绘师”，均超出给定来源。
- 多轮把反差扩写为艺术张力、复杂氛围或丰富层次。

这三个严重错误使该 case 仍有 37.5% 严重错误率，不能随另外两个 case 一起放行。

### 不完整档案前言

v4.2 八轮均把主对象锁定为“馆藏记录”，没有再推出对应实物、影像、存世作品或缺项不影响观看。该修复可靠。

质量上仍有两个限制：全部八轮都较清单化，任务功能均值只有 3.0；第 6 轮以“完整状态”描述含缺项资料，措辞含混。硬通过率为 0/8 是篇幅问题，不代表语义修复失败。

## 提示词污染与新回归

未发现明确的跨 case 泄漏：archive 的对象规则没有进入 emotion/art，emotion 的不归因规则也没有污染其他任务。

但 art 仍有来源边界污染：外部身份“日本艺术家、浮世绘师”进入文本，且边界字段继续列举尺寸、收藏地等未要求项目。这不是跨任务规则串线，但说明严格来源隔离仍不完整。

新回归主要是局部自然度问题，没有在 emotion 或 archive 产生新的严重错误：

- “更生的气”不自然。
- “孤独与加深”是明显病句。
- “现有资料的完整状态”与缺项并置，表意矛盾。

## 采用建议

现在将 v4.2 用于 `emotion_apology_anger` 和 `preface_incomplete_archive`。

`art_rich_contrast` 再做一次窄补丁后复测：锁定猎人为复数；只写“北斋”，不添加国籍或流派；反差只止于题诗冷寂与画面动作热闹，不扩写复杂氛围、艺术张力或丰富层次。
