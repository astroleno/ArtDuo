## 结论

task-routed-v4 的总体均分为 **18.333/20**，比 source-isolated-v3 的 **18.100** 高 0.233；平均 case 极差从 4.583 降至 3.583。但严重事实/语义错误没有下降，反而由 8/60（13.33%）增至 9/60（15%）。因此不能依据总体均分直接冻结 v4。

v4 的改进和回退都高度集中：它彻底修复了中性情绪、夜景结语、记录冲突等 case，却在 `art_rich_contrast` 中 4/5 次误套“不确定归属”模板，在 `emotion_apology_anger` 中 4/5 次增加未明示的情绪、经历或主客体错乱。当前最合理的架构是按 case family 路由，而不是只按 emotion / artwork / framing 三大类别路由。

## 方法

逐条读取 120 条最终流式输出，以每条内置的 Codex Sol max 与 Kimi K3 max 作为事实和功能参照，不以措辞相似度评分。五个维度均为 0–4 分：

- 证据忠实度（evidence fidelity）
- 任务功能（task function）
- 语义细腻度（semantic nuance）
- 自然度（naturalness）
- 边界与约束（boundary constraints）

性能、hard pass 和 variant 名称均不参与评分。

## 主要质量差异

### v4 明确更好的部分

- `emotion_neutral_now`：从 15.2、2 次严重错提升为五轮全 20，无虚构饭菜、追问或陪伴安排。
- `closing_night_photos`：人物身份没有再偷换为拍摄者，且未补背后故事；均分 +1.0。
- `art_record_conflict`：更稳定地并列冲突，不把矛盾美化为作品意义；均分 +1.2。
- `art_uncertain_attribution`、`closing_memorial_objects`：事实边界与任务收束更完整。

### v4 必须修复的部分

- `emotion_apology_anger`：4/5 严重语义扩写，说明情感路由仍把“细腻”误解成增加情绪与经历。
- `art_rich_contrast`：4/5 严重事实错误，是路由模板交叉污染，不是随机措辞问题。
- `preface_incomplete_archive`：记录单位和作品可见性没有硬约束，单轮最低 11 分。

## 最终建议

1. 不将 task-routed-v4 作为整包替换；保留 v4 的中性情绪、隐私边界、稀疏作品、记录冲突、不确定归属、夜景和纪念物分支。
2. `apology_anger` 改用严格的明示情绪白名单：只允许“道歉后更生气/愤怒增加/原因未知”，禁止委屈、不甘、困惑、等待、释然等未出现词义。
3. `rich_contrast` 与 `uncertain_attribution` 必须拆成不同模板。生成前建立字段状态表：作者为确定/存疑，日期为作品年代/记录日期，禁止模板自行改写状态。
4. `incomplete_archive` 固定实体为“12 条馆藏记录”，并声明无权推定作品存世、可见或可观看。
5. 增加模板污染检测：输出出现输入没有的“可能归于、记录日期非制作日期、存世作品”时直接拒绝，不做自由扩写式重试。

通过上述三处阻断项后，再做未见 case 的盲测；在此之前，v4 只能按 case family 有条件启用。
