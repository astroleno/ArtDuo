# 优化后的作品讲解Prompt

## 当前问题分析
1. 过度约束导致表达生硬
2. 代词禁用让语言不自然
3. token限制过低
4. 格式要求过于死板

## 优化版本1：简化约束，增加表现力

```typescript
const optimizedPrompt = `请为这件艺术作品写一段生动有趣的中文讲解，帮助"${emotion}"情绪的用户更好地理解和欣赏作品。

作品信息：
- 标题：${displayTitle}
- 艺术家：${artwork.artist}
- 年代：${artwork.year}
- 材质：${artwork.medium}
- 描述：${artwork.description || '暂无描述'}
- 收藏：${artwork.museum}

用户情绪：${emotion}
${userInput ? `用户想法：${userInput}` : ''}

请从以下角度展开讲解：
1. **第一印象**：用1-2句话描述作品给人的直观感受
2. **艺术特色**：分析作品的技法、色彩、构图等艺术特点
3. **情感连接**：说明作品如何与用户的"${emotion}"情绪产生共鸣
4. **背景故事**：介绍作品的历史背景或创作故事
5. **观看建议**：提示欣赏这件作品时可以关注的细节

要求：
- 用自然流畅的中文写作，避免学术化表达
- 总长度控制在200-400字
- 让讲解既有专业深度又通俗易懂
- 避免使用"产生共鸣"等套话，用具体描述代替`;
```

## 优化版本2：故事化叙述

```typescript
const storyPrompt = `请以讲故事的方式介绍这件艺术作品，帮助"${emotion}"情绪的用户建立情感连接。

作品：《${displayTitle}》
艺术家：${artwork.artist}
年代：${artwork.year}
材质：${artwork.medium}

用户心情：${emotion}
${userInput ? `用户想法：${userInput}` : ''}

请像一个热情的策展人一样，用300-500字的篇幅讲述：

1. **开篇吸引**：用一个有趣的问题或观察开始，抓住读者注意力
2. **作品故事**：介绍作品背后的创作故事或历史趣闻
3. **情感桥梁**：说明这件作品如何与"${emotion}"的心情对话
4. **艺术密码**：揭示作品中的艺术技巧或象征意义
5. **观看体验**：建议用户如何欣赏这件作品，可以获得什么感受

写作风格：
- 生动有趣，像在和朋友聊天
- 避免生硬的学术术语
- 多用感官描述（视觉、情感等）
- 让读者仿佛站在作品前听讲解`;
```

## 优化版本3：聚焦情感共鸣

```typescript
const emotionPrompt = `请为"${emotion}"情绪的用户专门定制这件艺术作品的讲解。

作品信息：
- 《${displayTitle}》- ${artwork.artist} (${artwork.year})
- 材质：${artwork.medium}
- 背景：${artwork.description || '暂无描述'}

用户情绪：${emotion}
${userInput ? `用户补充：${userInput}` : ''}

请写一篇400字左右的情感化讲解，重点回答：

**为什么这件作品特别适合现在"${emotion"的心情？**

1. **情绪呼应**：作品的色彩、构图或主题如何反映用户的心境
2. **治愈力量**：作品能带来什么样的情感慰藉或启发
3. **观看时机**：为什么现在看这件作品特别有意义
4. **情感收获**：欣赏后用户可能获得什么样的感受或思考

写作要求：
- 温暖、真诚、有同理心
- 避免空泛的赞美，要有具体的作品分析
- 让用户感觉这个讲解是为他/她量身定制的
- 语言优美但不过于文艺腔`;
```

## 配置优化建议

```typescript
// 优化调用参数
const optimizedConfig = {
  temperature: 0.7,  // 增加创造性
  max_tokens: 800,   // 增加到800token
  thinking: 'enabled' // 启用思考模式，提高质量
};

// 增加并发数
const scoringConfig = {
  maxConcurrent: 3,  // 从1改为3
  batchSize: 15,     // 从20改为15，减少单批token数
};
```

## 效果预期

1. **质量提升**：更自然流畅的表达，减少模板化
2. **情感连接**：更好地与用户情绪建立共鸣
3. **用户体验**：讲解更生动有趣，易于理解
4. **效率优化**：合理的并发设置，减少总耗时
