🎬 精讲作品（A 级）的特征设计建议

这些作品不再是“动的画”，而是“导演的场景”。
我们可以逐步加深表现层级（由轻到重）：

模块	描述	实现要点
🎯 焦点锚定（FocusDepth）	观众视角锁定关键人物或手势	点击 / 自动识别 / 预设深度均可
🫱 手势引导	在作品上出现手势或指向动画	可为 svg overlay / light streak / gesture mesh
🗣️ 语音旁白	以轻旁白讲述细节故事	本地 tts 或流式生成；配合滚动节奏
🔦 局部高光	当讲解特定部位时，局部亮度提升	动态mask或shader高光层
🌀 环境反应	背景景深 / 色调随讲解同步变化	调色 / Bloom / DOF动态联动
🪄 导演语言	使用 Dolly、Pan、Pull Focus 组合	每一镜头皆为叙事动作

换句话说：

“精讲作品不是更炫的图，而是更会讲故事的图。”

🧠 作品分级的生成逻辑（自动 + 策展混合）

我们可以这样构建：
	1.	语义层：
	•	分析作品的 metadata.description 与关键词数量
	•	如果有丰富叙事/人物/情感描写 → 候选 A/B 级
	•	若为抽象/背景/风景类 → 候选 C 级
	2.	情绪层：
	•	在情绪曲线的波峰/谷值处优先选 A/B 级
	•	保证每次展览的“峰”都被 A 级作品占据
	3.	策展层（人工/LLM修正）：
	•	LLM 最终根据整段叙事意图，锁定 1–2 幅 A 级作品（配讲解）
	•	其他作品自动分配到 B/C 段落

可以理解为：算法先选出潜力作品 → 策展LLM再定夺剧情节奏。
